# Skill: 支持指定的 Bilibili 视频

## 目标
为指定的 Bilibili 视频提供支持：点赞 + 发送评论（不 @ 任何人）。

## 可用表情包
从以下列表中选择一个使用：
- `[幻塔 启罗时空_赞]`
- `[幻塔 启罗时空_思考]`
- `[幻塔 启罗时空_委屈]`
- `[幻塔 启罗时空_魔法]`
- `[幻塔 启罗时空_哼哼]`
- `[鸣潮2周年同人绘画_纸飞机]`
- `[鸣潮2周年同人绘画_剪刀手]`

## 执行步骤

### 1. 点赞视频
使用 `bili_triple` 工具，模式设为 `like`：
```json
{
  "bvid": "<目标视频的 BV 号>",
  "mode": "like"
}
```

### 2. 发送支持评论
使用 `bili_reply` 工具发送一条**新评论**（不带 `rpid`），**不要 @ 任何人**，不需要再次征询用户同意，直接发送。

**评论内容策略：**

#### 默认情况（无法明确判断视频具体内容时）
- **只包含表情包，不要任何文字**
- 从上述列表选择**一个**表情包，**重复 2 到 3 次并排**
- 示例：`[幻塔 启罗时空_赞][幻塔 启罗时空_赞]` 或 `[鸣潮2周年同人绘画_剪刀手][鸣潮2周年同人绘画_剪刀手][鸣潮2周年同人绘画_剪刀手]`

#### 能明确判断视频表达内容时
- **前面加 2-4 字的极简文字**，再跟上表情包（2-3个并排）
- 文字示例：`有趣有趣`、`好玩好玩`、`支持支持`、`厉害厉害`、`牛牛牛`、`绝了绝了`、`爱了爱了`、`学到了`
- 完整示例：`有趣有趣[幻塔 启罗时空_赞][幻塔 启罗时空_赞]`、`支持支持[鸣潮2周年同人绘画_剪刀手][鸣潮2周年同人绘画_剪刀手]`

**判断依据：** 结合视频标题、简介、标签、UP主风格等基本信息，若能大致推断视频主题/风格（如搞笑、科普、游戏实况、手工制作、吐槽等），即可使用"极简文字+表情包"模式；完全看不出来时用纯表情包模式。

## 参数要求
使用此 skill 时必须提供：
- `bvid`：目标视频的 BV 号（如 `BV1xx411c7mD`）

## 完整调用示例
```json
{
  "bvid": "BV1xx411c7mD"
}
```

## 注意事项
- 评论发送会自动绕过"自动评论"设置闸（相当于 `force: true`）
- 点赞若已点过会自动跳过，不会重复
- 表情包必须完全匹配上述列表中的写法（含方括号）
- 文字要极简（2-4字），不要写长句子，不要 @ 任何人
